# MMPOI 上的 IER 第一阶段实现

## 目标

第一阶段把 MMPOI 原先的“每个 POI 一个平均评论向量”替换为可训练的证据通路：

1. 从原始 `review_summary.json` 恢复逐条评论；
2. 对评论做精确去重，使用冻结的 TF-IDF + TruncatedSVD-128 编码；
3. 用用户嵌入与当前 POI 嵌入构造查询；
4. 同时考虑查询相关性、可学习可靠性和近重复密度，选取 Top-K 评论；
5. 对选中证据做温度 softmax 聚合，通过零初始化残差接回 MMPOI；
6. 训练时使用证据 dropout、重复不变性损失和关键证据敏感性损失。

零初始化残差保证载入原基线检查点时，新增模块在第一个优化步骤之前不会改变原模型输出。没有原始评论的 POI 直接回退到 MMPOI 官方聚合评论向量。

## 数据可用性

- 图中 POI：4,618
- 有逐评论证据的 POI：3,933（85.17%）
- 进入证据库的去重评论：53,989
- 每个 POI 最多保留：20 条
- 原始精确重复评论移除：142 条
- 缺失逐评论证据的 POI：685，使用无损回退

证据张量位于 `artifacts/evidence/mmpoi_nyc_reviews_tfidf_svd128.npz`；可读评论索引位于同目录的 `*.reviews.jsonl.gz`。

## 已实现的鲁棒性协议

- `clean`：原始证据集合；
- `duplicate`：把每条证据复制一次；
- `noise`：每个 POI 注入 5 个固定随机噪声向量；
- `missing`：移除全部逐评论证据，检查回退路径；
- `sparse`：每个 POI 只保留第一条证据。

## 当前结果

从原 MMPOI 最佳检查点（epoch 32）热启动，训练 1 epoch：

先做了同设备、同随机种子的全模型 1-epoch 对照。IER 为
HR@20=0.6951、NDCG@20=0.4029；继续微调但关闭证据模块为
0.6976、0.4032。二者基本持平，但全模型波动掩盖了证据信号。

因此正式的第一阶段采用“冻结已复现基线，只训练证据适配器”，证据模块独立学习率为 1e-3，训练 5 epochs：

| 指标 | 原最佳检查点 | IER 最佳检查点 | 绝对变化 |
|---|---:|---:|---:|
| HR@1 | 0.182334 | 0.182634 | +0.000300 |
| HR@5 | 0.500940 | 0.503422 | +0.002481 |
| HR@10 | 0.625426 | 0.625426 | 0 |
| HR@20 | 0.700256 | 0.700256 | 0 |
| mAP@20 | 0.317036 | 0.317370 | +0.000335 |
| NDCG@20 | 0.405568 | 0.405832 | +0.000264 |
| MRR | 0.319469 | 0.319802 | +0.000333 |

这是“无损、小幅改善”，还不是足够强的最终论文增益。

五种证据扰动结果：

| 场景 | HR@20 | NDCG@20 | 相对 Clean NDCG |
|---|---:|---:|---:|
| Clean | 0.7003 | 0.4058 | 0 |
| Duplicate | 0.7003 | 0.4059 | +0.0001 |
| Noise | 0.7003 | 0.4056 | -0.0002 |
| Missing | 0.7003 | 0.4056 | -0.0002 |
| Sparse | 0.7003 | 0.4058 | 0 |

重复证据没有造成下降，噪声和缺失只产生很小回落；但这也部分源于当前证据残差较弱，因此必须同时报告准确率增益和扰动敏感度，不能只拿鲁棒性数字作结论。

## 限制与下一步

当前 TF-IDF+SVD 是为了先验证证据级建模、训练和鲁棒性实验闭环，而不是最终语义编码器。下一轮应替换为冻结的句向量编码器，引入“用户历史类别/属性原型”作为显式查询，并加入逐图片证据；接口和证据张量布局已经为此保留。当前 MMPOI 原始评论没有 helpful-vote 字段，因此可靠性弱标签需要采用用户历史匹配、多模型一致性或小规模人工标注，而不能声称使用了 helpful vote。
